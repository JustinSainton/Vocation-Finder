## Project Overview

Vocational Finder is a web and mobile application designed to help users identify, articulate, and act on their vocational direction. The platform guides individuals through a structured assessment process, uses AI-powered analysis to generate personalized vocational profiles, and provides actionable pathways including curated courses, job listings, and career coaching resources.

## Engagement and Timeline

I began work on the Vocational Finder project on **March 2, 2026**, and have been actively contributing to its development from that date through the present. This work is being done under our agreement, and my role on the project is that of a **developer**.

## Product Stage

The project is currently in the **MVP (Minimum Viable Product) stage**, with a working prototype that includes functional web and mobile applications, a complete assessment pipeline, AI-driven vocational profiling, and multiple supporting feature modules.

## Technical Contributions

I have performed the following technical tasks and contributed to the following areas of the platform:

### Platform Areas

- **User Intake Flow:** Built the multi-step vocational assessment experience, including 20 questions across 7 categories, supporting both authenticated and guest users.
- **Assessment Logic:** Implemented the scoring engine, question sequencing, and assessment state management across web and mobile platforms.
- **AI Output Generation:** Developed the two-phase AI analysis pipeline that generates personalized vocational profiles from assessment responses using the Anthropic AI SDK.
- **Front-End Interface:** Built 15 page modules for the web application — including Assessment, Dashboard, Courses, Jobs, Career Coach, Career Profile, Billing, Pathways, Resumes, Applications, and Admin — and 3 mobile application flows for Assessment, Authentication, and Dashboard.
- **Back-End Logic:** Developed controllers, API endpoints, middleware, queue jobs, and service classes powering the platform's core functionality.
- **Data Handling:** Designed and implemented the database schema using SQLite for development and MySQL for production, with UUIDs on all models and soft deletes throughout.
- **Prompt Design:** Authored AI prompts for vocational profiling, course personalization, and the conversational career coaching interface.
- **Course Personalization System:** Built a system for AI-generated personalized course content, including template-based content blocks, personalization prompts, and cached per-user content generation.
- **Testing and Debugging:** Ongoing debugging and stabilization of features including speech-to-text and text-to-speech integration, AI retry logic with exponential backoff, and cross-platform compatibility.

### Technologies and Stack

- **Backend:** Laravel 12, PHP, Inertia.js v2, Laravel Sanctum, Laravel Cashier (Stripe), Laravel Socialite (OAuth), Laravel AI SDK
- **Web Frontend:** React 19, TypeScript, Tailwind CSS v4, Vite 7
- **Mobile:** Expo 55, React Native 0.83, Expo Router, Zustand, React Native Reanimated
